 
Nirvriksh is a platform that helps users create and validate startup ideas, from the ideation stage to the MVP (Minimum Viable Product) stage. The project aims to provide a comprehensive solution for entrepreneurs to bring their ideas to life.

### Main Function Points
- Permet aux utilisateurs de créer et de valider des idées de démarrage, de l'étape de l'idéation à l'étape du MVP (produit minimum viable)
- Offre une solution complète pour les entrepreneurs afin de concrétiser leurs idées

### Technology Stack
projet utilise la technologie TypeScript, avec des outils tels que Vite, Tailwind CSS et d'autres technologies web modernes.
